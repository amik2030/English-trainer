🔬 How it works

Three agents, one hybrid retrieval pipeline, mandatory human-in-the-loop. Low autonomy by design.

🔍 Monitor — "The Sentinel"

Scheduled (6h) + event-driven. Watches EDPB, EUR-Lex, 3–5 expert sources, selected DPAs. Emits structured events: {source, type, url, change_delta}. Does not interpret.

Cron + queue HITL: source approval

📋 Summarizer — "The Librarian"

Raw event → structured summary (≤500w) + embeddings + relevance/risk tags + citation links to internal policies. Triggers alerts on high impact. Does not answer users.

Queue consumer HITL: spot-checks

🧠 Researcher — "The Counsel"

User query → parse → hybrid retrieval → citation-verified synthesis → confidence scores → gap flags → mandatory human review gate. Does not crawl live or decide autonomously.

Interactive HITL: approval mandatory

Retrieval pipeline (why generic RAG fails for legal)

Query parser → Vector search (top-20) + BM25 (top-20) → Reciprocal rank fusion → Context builder (cross-refs, temporal) → LLM synthesis → Claim verification (NLI) → Human gate
  • Legal-aware chunking — Article → Paragraph → Point, never token counts. Art. 6(1)(b) ≠ Art. 6(2).
  • Citation graph — edges: AMENDS · INTERPRETS · REFERENCES · IMPLEMENTS · SUPERSEDES · APPLIES_TO · CONFLICTS_WITH
  • Anti-hallucination — every claim: ✅ SUPPORTED · ⚠️ PARTIAL · ❌ UNSUPPORTED (removed) · 🚫 FABRICATED (removed + logged)
  • Temporal versioning — "what did Art. 6 say in 2020 vs. now"
